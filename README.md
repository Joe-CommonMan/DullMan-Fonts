# DullMan-Fonts
A free and Open Source (source shapes/strokes) series of Typefaces that would suit for plain ol things.
DullMan Sans: Clone of Arial but is in its early stage so there's unedited letters in other languages.
DullMan MaxEd: Clone of the Mac version of Helvetica with the letters based on the old 24pt designs.
If you wanna make or edit more glyphs make sure the stroke width for Roman is 0.4MM with the source font being on 13pt.
